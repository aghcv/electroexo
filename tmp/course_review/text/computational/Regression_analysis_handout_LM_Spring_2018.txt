Nonlinear regression 
o Every nonlinear regression method follows the following general steps: 
1. Start with an initial value for each 
model parameter. 
2. Generate the model solution for 
these parameter values. 
3. Calculate the sum-of-squares 
difference (SSD) between data 
and model solution 
4. Adjust the parameters to make the model solution come closer to the data 
points.  
5. Repeat steps (2-4) until parameter adjustments make virtually no difference in 
the sum-of-squares based on some criterion.  
6. Stop. The final values are the least squares estimates (best fist values) of the 
model parameters 
 
o Step 4 is the most difficult step.   
o There are several algorithms for adjusting model parameters (step 4).  
▪ One such iterative method that is widely used and is the basis for many 
other methods is the Gauss-Newton method. 
▪ Other methods include: 
- Method of steepest descent 
- Simplex method 
- Levenberg-Marquardt method (hybrid of the steepest descent 
and Gauss-Newton)

Convergence and local minima: 
▪ For linear regression (linear models), there is one unique minimum.  
▪ For Nonlinear regression, depending on the model, there may be 
several local minima. 
o The smallest is called global minimum (best fit).  
o Thus, sometimes the estimated parameter values to which nonlinear 
regression converges to from a given initial values are not the same as 
those for the best possible fit in the least square sense. 
 
▪ To determine whether your nonlinear regression program converged to the 
values corresponding to the global minimum: 
1. Choose reasonable initial values for the parameters. 
2. Make sure that the estimated values make sense scientifically. 
3. Repeat nonlinear regression several times using different initial values for 
the model parameters.

✓ Matlab optimization function: lsqcurvefit 
o Implements the Levenberg-Marquardt method 
o General function form: 
[x, resnorm, residuals, exitflag, output, lambda, jacobian] = 
lsqcurvefit(@my_model, x0, xdata, ydata, lb, ub, options, P1, P2, …) 
where, 
x = vector with the least square values of the model parameters 
resnorm = Sum of squares difference between data and best fit 
residuals = model fit – data 
exitflag = integer identifying the reason the algorithm terminated. “1” 
indicates that the function converged to a solution x 
output =  structure containing information about the optimization, 
including the # of iterations taken to converge to a solution for x. 
lambda: The Lagrange multipliers at the solution x. lambda is a structure 
where each field is for a different constraint type. 
jacobian: The value of the Jacobian of fun at the solution x.  
 
my_model.m = a function that defines the model to be fitted to the data 
x0 = initial values of the model parameters 
xdata =  vector of the predictor (independent) variable 
ydata = vector of response (dependent) variable 
lb = lower bounds on model parameters (x) 
ub = upper bounds on model parameters  
options = allows user to specify optimization method, maximum number 
iterations, termination criteria, etc. Use the function optimset to 
control these parameters  
P1, P2,… = constants that can be passed directly to the function my_model

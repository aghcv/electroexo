Numerical Methods for Solving ODEs of the Initial Value Type 
 
 
 Most of the differential equations that we have encountered so far have 
been simple enough (linear) to obtain an analytical or exact solution 
(direct integration, Laplace transform, eigenvalue-eigenvector 
method (lsim, dsolve, etc.)).  
 
 For system of ODEs when obtaining an exact solution is difficult or 
impossible (e.g., most nonlinear ODEs, second order or higher linear 
ODE with variable coefficient), numerical methods are needed to 
approximate the solution.

 Numerical methods for solving ODEs can be classified as either one step 
methods, or multi-step or continuing methods. 
 
o One step methods:  
 Only the knowledge of C(ti) = Ci is required to determine Ci+1 = C(ti+1), 
where  ti + 1 = ti + h .  
 
 One step methods include: 
o Euler method 
 
o Runge-Kutta methods. 
 
o Multi-step methods:  
 For this class of numerical methods, the knowledge of values of C at 
more than one previous point is required to determine the next point. 
 
 For example, to determine Ci +1 = C(ti +1), the knowledge of Ci, 
Ci1 and Ci 2 is required.  
 
 Adams-Moulton method.

What are the sources of error in the approximate solution and how can we 
control this error? 
 
 Two main sources of error: 
1. Formula (aka accumulated or truncation) error: For the Euler 
method, after n steps 
 
En = formula error = Cn  Cn 
 
Two factors contribute to En: 
 
a. At each time step, an approximate formula (Euler formula) is 
used to estimate Cn by Cn. 
 
b. At each step (except for the first step), the input data (point 
and slope) used in the Euler formula are also approximations 
of the actual input data. 
 
2. Round-off error: Due to lack of computational accuracy.  
 
a. This error depends on the type of computer used and on the 
method of rounding off used (single versus double precision). 
 
b. For MATLAB, double precision is the default rounding off 
method. 
 
c. This type of error is cumulative.

 Runge-Kutta methods: 
 
 Carl Runge and Wilhelm Kutta were able to develop formulas that are 
equivalent in accuracy to higher order Taylor series: 
 
o Do not involve higher order derivatives  
 
o Are known as the Runge-Kutta methods 
 
dC
dt = f(t, C) ; C(t = t0) = C0
 
 
 For a given time interval ti  t  ti+1, the Runge-Kutta methods involve using 
weighted average of values of slopes taken at different points within the 
interval (ti, ti + h).

  One step numerical methods for solving a system of first order ODEs: 
 Both Euler and Runge-Kutta methods are applicable for a system of ODEs 
(multi-compartmental model). 
 
 To solve a system of N first order ODEs using one step methods, we need N 
independent initial conditions for the N state variables.  
 
 Again, all equations must be solved simultaneously.

 Numerical (vs. inherent) Stability:  
o Concerned with the effect of perturbations (formula or round-off error) 
on the numerical method.  
 
o A given method is said to be stable if the error introduced at each 
step decays with time. 
 
 For a given h, a numerical method is said to be stable if the 
change due to perturbations (formula error) of size n in Cn is no 
larger than m in all subsequent values of Cm, m > n. 
 
 Convergence requires numerical stability, but stability does not require 
convergence.

 Well-posed problem:  
 Means that small changes in the stated problem will only lead to small 
changes in the answers. 
 
 The problem for which a numerical solution is desired is useful to be 
well-posed since numerical approximations introduce perturbations 
(formula or round-off error). 
 
 
 Stiff differential equations: 
 Stiffness occurs when greatly different rate constants (eigenvalues) 
exist in the same set of differential equations.  
o The fast rate constant controls the stability of the solution and 
hence the size of h (when using one step methods), 
 
o although most of the solution is determined by the reactions with 
slow rate constants.  
 
 For stiff equations, use Adam’s Moulton or Gear’s method instead of 
one-step methods.

MATLAB (ode45) 
- Several functions in MATLAB that may be used for numerical integration of 
ODEs of the initial value type (see Table 7.2 in text).   
 
- The function (or solver) that we will use is ode45, which uses the 4th order 
Runge-Kutta method. 
 
dy/dt = f(t,y)     subject to y(0) = y0 
Syntax: 
 [T,Y] = ode45(@name_func, tspan, y0, options, p1, p2,…) 
 
where, 
 
o name_func: Name of the m-file function (name_func.m) containing the function 
name_func that evaluates the right hand side of the ODEs. This function must 
return a column vector corresponding to f(t,y) of the ODEs. 
 
Note: “name_func.m” should be in the same workspace as the “main” function 
 
o tspan: A vector specifying the interval of integration of the ODEs. To 
obtain solution at equally spaced intervals,  
    tspan = [t0:dt:tf] 
where dt is the user’s choice of spacing between points where the output 
will be given. 
 
Note: dt is different from the step size that is used to solve the ODE, which 
is set internally by the Matlab function

o y0 = The vector containing the initial conditions of the ODEs 
 
o options: Optional integration argument created using the odeset function. 
 
options = odeset('RelTol', 1e4,'AbsTol', [1e4 1e4 1e5]); 
 
RelTol: relative error tolerance in each integration step 
AbsTol: absolute error tolerance  
 
o p1, p2, …: Optional parameters that the solver (ode45) passes to 
name_func and all the functions specified in options. 
 
o [T,Y]: the solver returns the values of the independent (T) and dependent 
(Y) variables in the arrays T and Y, respectively.  
 
 Each row in array Y (# of columns = number of ODE’s or state 
variables) corresponds to the solution of the ODE’s at a time returned 
in the corresponding row in the column vector T.

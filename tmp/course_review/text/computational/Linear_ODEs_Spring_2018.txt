coefficients (time-invariant) ODEs of the initial value type (IVP): 
 
dx1/dt = a11 x1 + a12 x2 +…… + a1n xn    ;   x1(t0) = x10

. 
. 
. 
dxn/dt = an1 x1 + an2 x2 +…… + ann xn      ;   xn(t0) = x10 
 
o The above system of ODEs can be rewritten in a matrix notation: 
 
dX/dt = AX    with the initial conditions X0 
 
where X(t) and X0 are column vectors representing the states and initial values, 
respectively. 
 
X(t) =
x1(t)
x2(t)
...
xn(t)
  is an n x 1 matrix             
X0 =
x10
x20
...
xn0     and A = (aij) is an n x n matrix  
o A system of ODEs of this form has a closed form solution that can be readily 
obtained using the eigenvalue-eigenvector method.  
 
The solution of the above system of equations in matrix notation is: 
 
X(t) = [V etV] X0 
 
 (V etV) referred to as state transition matrix 
 Columns of V are the eigenvectors of the matrix A 
 V is the inverse of V  
 Diagonal elements of the diagonal matrix  are the eigenvalues (poles) of 
the matrix A  
 t is time.

% Solution of a system of two coupled, linear, constant coefficient, 
% homogeneous ODES of the initial value type using the 
% Eigenvalues-Eigenvectors method 
 
A = [4 2; 3 -1]; 
C0 = [1 ; -1]; 
  
[V, lambda] = eig(A); 
  
t = [0: 0.1: 1.0]; 
  
c  = zeros(length(t), 2); 
cc = zeros(length(t), 2); !compare to closed form solution using  
                          !Laplace transform 
B = inv(V); 
 
for i = 1:length(t) 
    W = V*expm(lambda*t(i))*B*C0; 
    c(i,1) = W(1,1);  ! C1(t) 
    c(i,2) = W(2,1);  ! C2(t) 
end 
  
%  Solution of C1(t) using Laplace Transform 
for j = 1:length(t) 
    cc(j,1) = (3.0/7)*exp(-2*t(j)) + (4.0/7)*exp(5*t(j)); 
end 
 
% plot data 
  plot(t,c(:,1),'rx', t, cc(:,1), 'bd'); 
  title('Y1(t)'); 
  xlabel('time (sec)'); 
  ylabel('concentration (Molar)');

- How do you find V and ? 
 
(A - I)V = 0 
 
o The diagonal elements of  are the eigenvalues (i) of A. The columns of V 
(vi) are the eigenvectors of A.  
o det(A –  I) = 0  is called the characteristic equation and its roots are the

o The number i is called an eigenvalue of the n x n matrix A provided that: 
 
   det(A –  i I) = 0  
 
o An eigenvector associated with the eigenvalue i is a nozero vector vi such that  
 
(A – i I) vi = 0
